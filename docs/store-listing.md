## Name
Spaces Sidebar — Arc-style spaces & pinned tabs

## Short description (132 max)
Arc-style sidebar for Chrome: Spaces, folders and pinned tabs that reopen in their own tab. One-step import from Arc.

## Description
Arc stops working on December 22, 2026. Spaces Sidebar brings its sidebar to Chrome's native side panel.

- Spaces with their own icon and color. Click or swipe to switch.
- Pinned tabs and folders. A pin opens in its own tab and returns to it on the next click, without duplicates.
- Open tabs listed under the pins. Drag to pin, drag onto a Space to move.
- Optional: tabs per Space, using Chrome tab groups.
- Import from Arc: drop StorableSidebar.json on the panel. Spaces, folders, pinned tabs and Favorites come over.
- Import of bookmarks.html, JSON backup and restore.
- Search across all Spaces. Light and dark themes.

Everything stays on your device: no account, no network requests, no analytics. Open source (MIT).

Not affiliated with The Browser Company. Arc is a trademark of its owner.

## Single purpose
A sidebar for organizing pinned tabs into Spaces and folders and switching between them.

## Permission justifications
- sidePanel: the extension's UI is a side panel.
- tabs: lists the window's open tabs (title, URL, favicon) in the panel, pins the current tab, activates or closes a tab on click.
- tabGroups: optional mode that keeps one tab group per Space and collapses the others.
- storage: stores the user's Spaces and pinned tabs locally.
- favicon: shows site icons next to pinned tabs.
- Remote code: none.

## Data usage
Does not collect or transmit user data. Privacy policy: PRIVACY.md in the repository.
